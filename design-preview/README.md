# Design preview harness

Renders the **real engine CSS**, our design frame (`our-skin.css`) and the engine's
**runtime-injected Svelte styles** in the exact cascade order the app uses
(`content.css → our-skin.css → runtime styles`), against representative engine DOM:
the drawer (login-icon → settings), the "+" attach bottom sheet, settings groups and
switches — in dark and light.

Use it to iterate on the design frame without building the APK:

```bash
design-preview/setup.sh                                 # one-time / after engine updates
python3 -m http.server 8080 --directory design-preview  # then open /preview.html
```

Committable files here: `preview.html` (the fixture page), `setup.sh` (assembles the
cascade). Everything else (`content.css`, `our-skin.css`, `runtime-styles.css`) is
generated by `setup.sh` from the current engine bundle — do not hand-edit.
